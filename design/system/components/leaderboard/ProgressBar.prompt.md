Rounded gradient progress bar for quota attainment and goal pacing.

```jsx
<ProgressBar value={82} tone="up" label="Quota" showValue />
<ProgressBar value={128400} max={150000} tone="gold" valueLabel="£128.4k / £150k" label="Q3 target" />
```

Props: `value`, `max`, `tone` (`brand`/`up`/`down`/`gold`/`sky`), `size`, `label`, `valueLabel`, `showValue`.
