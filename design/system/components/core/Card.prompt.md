Rounded surface container for grouped content. Optional title/action header, colored glow, and hover lift.

```jsx
<Card title="This week's movers" action={<Badge live>LIVE</Badge>}>
  …
</Card>
<Card glow="gold" interactive>Champion panel</Card>
```

Props: `glow` (`brand`/`gold`/`up`/`down`) · `interactive` · `flush` (full-bleed) · `title` · `action`.
