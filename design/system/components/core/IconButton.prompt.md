Square or round button for a single icon — toolbars, row actions, kebab menus. Always pass `label`.

```jsx
<IconButton label="Settings"><GearIcon/></IconButton>
<IconButton variant="solid" round label="Add"><PlusIcon/></IconButton>
<IconButton variant="ghost" size="sm" label="More"><DotsIcon/></IconButton>
```

Variants: `soft` (default) · `solid` (blue) · `ghost`. Sizes: `sm`/`md`/`lg`. `round` for a pill.
